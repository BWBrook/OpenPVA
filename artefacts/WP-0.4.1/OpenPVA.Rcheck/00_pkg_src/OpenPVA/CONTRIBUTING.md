# Contributing to OpenPVA

Thank you for considering contributing! OpenPVA is a community-driven project, and we welcome bug reports, feature suggestions, code improvements, documentation, and more.

## How to contribute

- Fork the repo and clone it locally
- Create a branch for your contribution
- Use consistent function documentation (roxygen2 style)
- Run tests via `testthat` before submitting
- Submit a pull request with a clear description

## Need Help?

Open an issue or email the project maintainer.
