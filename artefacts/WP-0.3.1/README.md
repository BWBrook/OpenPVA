# WP-0.3.1 artefact bundle

This bundle captures smoke-check evidence for `WP-0.3.1`.

## Commands run

1. `Rscript bootstrap_env.R`
2. `Rscript -e "devtools::test()"`
3. `Rscript -e "targets::tar_make(...names = c('sim_basic_reps_extinction_summary','sim_basic_dense_harvest_trajectory_plot'))"`
4. Toy scenario run with fixed seed (`set.seed(123)`) using `run_basic_simulation_replicates()`.

## Key evidence files

- `bootstrap_env.log`: environment bootstrap/restore transcript.
- `session_info.txt`: R session info.
- `tests_devtools.log`: full test output.
- `test_summary.txt`: concise test summary.
- `targets_smoke_forced.log`: forced minimal targets run.
- `targets_summary.txt`: concise targets summary.
- `sim_basic_dense_harvest_trajectory.png`: demo plot generated by targets.
- `toy_extinction_summary.csv`: toy scenario extinction summary.
- `toy_mean_trajectory.csv`: toy scenario mean trajectory.
- `toy_scenario_outputs.rds`: serialized toy outputs.

## Sanity note

No immediate pathologies observed in the toy run. Extinction probability at threshold 10 was `0` across 5 runs, and mean trajectory remained finite and positive over 20 years.

- `renv_status.log`: post-bootstrap renv consistency check (project in sync).
