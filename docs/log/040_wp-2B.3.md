# Log 040 — WP-2B.3 YAML schema v3 uncertainty integration

## Date
- 2026-02-09

## WP

## Summary
- Implemented additive schema v3 uncertainty parsing, enforced schema-version
  discipline for uncertainty blocks, and added migration/snapshot regression
  coverage with YAML-driven ensemble evidence.

## Changes made
- Updated YAML parser and scenario contracts:
  - `R/scenario.R`
    - `scenario_spec()` now documents and carries optional `uncertainty_spec`.
    - Added schema v3 validator/migration helpers:
      - `.validate_yaml_cfg_v3()`
      - `.migrate_yaml_v2_to_v3()`
      - `.parse_uncertainty_yaml()`
    - `read_scenario_yaml()` now supports `schema_version: 3` uncertainty
      block parsing and stores validated `scenario$uncertainty_spec`.
    - Schema v2 now rejects `uncertainty` blocks with explicit migration
      guidance to v3.
    - Preserved v2 reproduction compatibility semantics in v3 by applying
      legacy `breeding_fun`/`fecundity_fun` adaptation for schema `>= 2`.
- Updated ensemble API fallback behavior:
  - `R/uncertainty_ensemble.R`
    - `run_scenario_ensemble()` now supports `uncertainty_spec = NULL` and
      falls back to `scenario$uncertainty_spec`.
- Added/expanded tests:
  - `tests/testthat/test_scenario_yaml_demography.R`
    - schema v3 uncertainty parse/run path.
    - schema v2 uncertainty rejection error path.
    - v2 -> v3 migration helper behavior.
  - `tests/testthat/test_reproducibility_snapshots.R`
    - new schema v2 -> v3 migration snapshot gate.
  - `tests/testthat/_snaps/reproducibility_snapshots.md`
    - added snapshot fixture for v3 migration output.
- Updated docs/reference:
  - `docs/reference/yaml_schema_v1.md`
  - `docs/reference/uncertainty_api.md`
  - `docs/reference/output_schema.md`
