# Agent guidelines

`AGENTS.md` is the governing repository instruction. Read it first, followed by
`vision_and_scope.md`, `architecture_core.md`, and the Goal 001 design documents.

The current runtime is an ordered list of validated ordinary R lifecycle
processes. The former fixed six-label dispatcher is retired. Do not restore it
through labels, controller branches, privileged parameter channels or
compatibility adapters. A contributed process must compose through the public
process/result contract without editing the controller or registering a global
name.

Keep implementation lean: ordinary functions and named lists, explicit
requirements/writes, engine-owned time/RNG/provenance, and focused scientific
tests. Do not introduce a DSL, plugin framework, registry, dependency-injection
system, or S4/R6 process hierarchy. Genetics, space, density and management are
optional processes, not postponed product phases or privileged engine domains.

No backwards-compatibility preservation is required. Remove obsolete paths and
update their call sites, tests and current documentation together. Do not guess
biological defaults or expand a goal beyond its stated scientific boundary.
