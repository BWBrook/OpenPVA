# Goal 009 - One coherent lean product surface

## Objective

Remove dormant controller-era lifecycle, old-output analysis and broken release
surfaces so the package exposes one coherent process-native product, while
retaining useful explicit demographic table builders and all accepted Stage 3
science.

## Required outcomes

1. Delete direct lifecycle mutators, random population initialisation and
   packaged biological defaults that bypass or pre-empt the process contract.
2. Retain demographic table validators/builders, but require explicit complete
   age/sex coverage at lookup with no silent zero or extrapolation.
3. Delete the dormant summary/plotting/management/uncertainty/calibration/
   sensitivity chain, its exports, exclusive tests, help and unused helpers.
4. Remove the broken release-evidence script and reconcile current package,
   API, workflow, CI, release and programme records with executable reality.
5. Remove only dependencies made unambiguously unused by this deletion.

## Non-goals

Stage 4 analysis/reporting, a replacement harvest process, engine or benchmark
splitting, broad test trimming, lockfile churn, tracked artefact/history pruning,
compatibility adapters, publication or release.

## Acceptance evidence

- Deleted-API and caller residue scans distinguish active code/docs from
  retained historical or deferred sources.
- Focused table, process, spatial, benchmark and pedigree tests pass.
- The full test suite and one canonical benchmark execution pass.
- An isolated R 4.6.1 source build and ordinary package check pass.
- Namespace/help/Collate consistency and `git diff --check` pass without new
  worktree artefacts.

## Publication boundary

No staging, commit, push, tag, release or publication is authorised.
